# Портфолио сайт

Статический сайт-портфолио по макету Figma.

## Как открыть

Локальный сервер уже можно запускать из папки проекта:

```bash
python3 -m http.server 4173
```

После запуска открыть:

```text
http://127.0.0.1:4173
```

Также сайт можно открыть напрямую через `index.html`, но через локальный сервер поведение ближе к обычному сайту.

## Что внутри

- `index.html` — структура страницы и контент.
- `styles.css` — вся адаптивная верстка под desktop / tablet / mobile.
- `assets/*.jpg` — сжатые изображения, которые реально используются на сайте.
- `assets/*.png` — исходные изображения из Figma, оставлены как резерв.

## Кейс Fluento

- `cases/fluento.html` — отдельная страница кейса.
- `case.css` и `case.js` — адаптивная компоновка, галерея, просмотр изображений и контакты.
- `assets/fluento/` — оптимизированные изображения из предоставленных материалов.
- На компьютере галерея прокручивается отдельно, а описание и контакты — вместе со страницей. На планшете и телефоне используется обычная прокрутка.
- Первый блок содержит беззвучное зацикленное MP4 с автозапуском через `data-video-src`. Если браузер отклоняет запуск, используется анимированное WebP из `data-video-preview` с кнопками паузы и перехода к полному плееру. При уменьшении движения резервное превью остаётся статичным.

## Остальные страницы кейсов

- `cases/habrix.html` — Habrix.
- `cases/lt-project-group.html` — LT Project Group.
- `cases/the-fifth-form.html` — The Fifth Form.
- `cases/green.html` — садовый центр Green.
- `cases/paypulse.html` — PayPulse.
- Все страницы используют общие `case.css` и `case.js`. Название для отправки берётся из `data-project-name`, ссылка — из canonical, описание — из meta description.
- У всех пяти веб-проектов подключены MP4 и резервные анимированные WebP. В PayPulse видеоблока нет.
- Изображения находятся в соответствующих подпапках `assets/`. Файлы `.fig` и исходные тяжёлые экспорты в публикацию не входят.
